When a cycle ends (or you decide to reset), an owner starts the next one from **Admin → OKR Cycle**.

<Steps>
  <Step title="Click Start new cycle">
    You'll be asked to confirm: _"Start a fresh cycle now? The current cycle will be archived."_
  </Step>
  <Step title="Confirm">
    The current cycle is archived and a fresh one begins, labelled automatically from your cycle length — **Q3 2026**, **H1 2026**, and so on. You'll see _"New cycle started."_
  </Step>
</Steps>

## What starting a new cycle means

- **OKRs do not carry over.** The new cycle starts with no objectives for anyone — company objectives included. Past OKRs stay with the archived cycle.
- **Check-ins reset** — week counting starts at Week 1 of the new cycle.
- Dashboards immediately reflect the new (empty) cycle, so expect 0% progress everywhere until OKRs are set.

## Right after — the rollover checklist

1. Owners set the new [company objectives](/admin/company-objectives).
2. The CEO sets their exec OKRs.
3. Managers set OKRs for every report — see [Setting OKRs for your team](/managers/setting-team-okrs).
4. Top-level people add their own.

The full sequence is written up as a workflow: [Quarterly rollover](/workflows/quarterly-rollover).

<Note>
  There's no undo — archiving is one-way, so start a new cycle only when the company is ready to re-plan.
</Note>
