title: "Creating an OKR"
sidebarTitle: "Creating an OKR"
description: "How to add an OKR for yourself or a team member using the Add OKR form."
---

You'll see an **Add OKR** button on your Personal Dashboard (for yourself, if you're allowed — see [Who sets whose OKRs](/okrs/who-sets-okrs)) and on each team member's profile (for managers).

<Steps>
  <Step title="Write the objective">
    One ambitious, qualitative line — e.g. _"Ship the new onboarding flow"_. Optionally add **Context** explaining why it matters this quarter.
  </Step>
  <Step title="Add key results">
    The form starts with two rows — use **Add key result** for more. For each one set:

    - **Measurable result** — what will be true, e.g. _"Activation rate"_.
    - **Type** — **Percent**, **Scale 1–10**, or **Status**. See [Key result types](/okrs/key-result-types).
    - **Target** — the number you're aiming for (percent and scale types).
  </Step>
  <Step title="Save OKR">
    The OKR appears on the owner's dashboard immediately, starting **On track**, and its key results join their weekly check-in from now on.
  </Step>
</Steps>

<Tip>
  Stuck staring at a blank form? **Suggest with AI** drafts objectives and key results grounded in the company's OKRs and the person's role profile — see [AI OKR suggestions](/okrs/ai-suggestions).
</Tip>

<Note>
  Company objectives are created separately by owners on the Company Dashboard — see [Company objectives](/admin/company-objectives).
</Note>
