## Editing an OKR

Open the OKR's edit page from the dashboard or profile where it appears (the same permission rules apply as for creating — see [Who sets whose OKRs](/okrs/who-sets-okrs)). You can:

- Reword the **objective** and its **context**.
- Edit each key result's **measurable result**, **type**, and **target**.
- **Add key result** rows.
- Remove key results — removed key results are deleted along with their history, so prefer marking one **Done** or **Off track** if the record matters.

Changes apply immediately; the next weekly check-in reflects the new set of key results.

## Deleting an OKR

Deleting removes the objective and all its key results from the cycle. Progress roll-ups recalculate without it. There's no undo — if the goal was attempted and abandoned, consider setting its status to **Off track** instead, so the cycle tells the true story.

<Tip>
  Mid-cycle edits are healthy — refining a target beats tracking a number everyone has stopped believing in. Just avoid rewriting objectives so often that week-to-week progress loses meaning.
</Tip>
